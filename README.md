# Landing Page Toolkit

Template de **landing page responsiva** para pequenos negócios (salões, estúdios, clínicas, prestadores de serviço em geral), com seções prontas de serviços, sobre, depoimentos e um CTA direto para **WhatsApp**.

Feito para ser rapidamente customizado por cliente: trocar cores, textos e o número de WhatsApp já entrega uma página pronta para publicar.

## ✨ Funcionalidades

- Seções: hero, serviços, sobre, depoimentos e CTA final
- Botão flutuante de contato via **WhatsApp** (link `wa.me`) em dois pontos da página
- Totalmente responsivo (mobile-first)
- Sem frameworks — fácil de hospedar em qualquer lugar (GitHub Pages, Netlify, hospedagem simples)

## 🛠️ Tecnologias

- HTML5
- CSS3 (grid/flexbox)
- JavaScript puro (Vanilla JS)

## ▶️ Como usar

```bash
git clone https://github.com/marquxst/landing-page-toolkit.git
cd landing-page-toolkit
# edite index.html e style.css com as informações do cliente
```

Pontos para customizar por projeto:

1. Nome da marca (`.brand`) e cores (`:root` em `style.css`)
2. Textos de cada seção (proposta de valor, serviços, sobre, depoimentos)
3. Número de WhatsApp nos links `https://wa.me/55...`
4. Imagem/gradiente do hero (`.hero-image`)
